# Узлы связи (УС): учёт оборудования

## Что сделано

### Backend
- В модель `Object` добавлены поля:
  - `switches_count` — количество коммутаторов
  - `routers_count` — количество роутеров / L3
  - `children_count` — количество дочерних объектов
- Обновлены Pydantic-схемы (`ObjectBase`, `ObjectCreate`, `ObjectUpdate`, `ObjectOut`)
- Автомиграция SQLite: `migrate_object_equipment_columns()` в `database.py`

### Frontend
- При выборе типа **УС (узел связи)** в модалке объекта показывается блок «Оборудование узла связи»
- Сохранение/редактирование передаёт новые поля в API
- Бейджи типов и статусов в таблице объектов
- `us-equipment-patch.js` — runtime-патч поверх стабильного UI

## Как проверить
1. Перезапустить backend (миграция колонок при старте)
2. Объекты → Добавить объект → тип «УС (узел связи)»
3. Заполнить коммутаторы / роутеры / дочерние → Создать
4. В таблице для УС отображаются бейджи статуса

## Примечание по UI
`index.html` временно загружает стабильный снимок UI из коммита `49c69516` и подключает патч.
Полный монолитный `index.html` с встроенными правками можно вернуть отдельным коммитом.
