# Система управления ППР — ОСС / АПК

Веб-приложение для учёта и контроля планово-профилактических работ  
филиала **ТОО «Satory Company ltd»** г. Усть-Каменогорск.

## Что реализовано

### Модули
| Модуль | Описание |
|--------|----------|
| **Дашборд** | Сводка по объектам, % выполнения ППР, графики, просрочки |
| **Задачи ППР** | Список задач, фильтры по статусу, отметка «Выполнено», создание новых |
| **Объекты** | Реестр ИНТ (145), ВОЛС (34), поиск, фильтр по типу |
| **Ежедневный контроль** | Форма по разделу 2 Положения ОСС + история |
| **Регламент** | Полный перечень из Положения ОСС + виды работ АПК (7.5–7.8) |
| **Шаблоны** | 19 шаблонов работ с периодичностью и составом |

### Данные
- Импортированы объекты из `Отчет_ППР_АПК_СЕНТЯБРЬ_2026г..xlsx`
- Загружены шаблоны из «Положение ОСС ППР»
- Созданы демонстрационные задачи на октябрь 2026

## Запуск

```bash
cd backend
python3 -m uvicorn main:app --host 0.0.0.0 --port 8000
```

Открыть в браузере: **http://localhost:8000**

API-документация (Swagger): **http://localhost:8000/docs**

## API (основные эндпоинты)

- `GET  /api/dashboard` — статистика
- `GET  /api/objects` — объекты (`?object_type=camera_integration&search=...`)
- `GET  /api/plans` — задачи ППР (`?status=planned`)
- `POST /api/plans/{id}/complete` — отметить выполненным
- `GET/POST /api/daily-checks` — ежедневный контроль
- `GET  /api/templates` — шаблоны
- `GET  /api/regulations` — текст регламента
